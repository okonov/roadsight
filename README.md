# roadsight
The application provides user ability to create routes and check images from publicly available traffic cameras along the routes.

## Documentation
- [Add Route — design & implementation plan](docs/add-route-design.md)

## Setup
Docker is used for local development.  
Install WSL2. PowerShell (admin):
```
wsl --install
```
Check WSL2 is installed
```
wsl --list --verbose
```
